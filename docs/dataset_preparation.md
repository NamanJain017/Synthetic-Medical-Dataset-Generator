# Dataset Preparation

Before training, you must acquire the real medical imaging datasets.

## Modality Sources
* **X-Ray:** CheXpert, MIMIC-CXR
* **CT:** LIDC-IDRI, RSNA PE
* **MRI:** BraTS, fastMRI
* **Mammography:** CBIS-DDSM
* **Ultrasound:** EchoNet-Dynamic

## Extraction
Run the appropriate script in `data/download_scripts/` to fetch or get instructions for downloading the data.
